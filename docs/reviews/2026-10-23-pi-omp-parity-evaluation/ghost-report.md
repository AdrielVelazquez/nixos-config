### Gates, presentation and keys

- [C] `spelling.autocomplete` is an enum with `off`, `auto`, `ngram`, `smollm`, `apple`; the default is **`auto`**. `auto` resolves to n-gram; choosing `apple` outside Darwin also resolves to n-gram. `smollm` is opt-in and downloads weights on first use in upstream OMP. Local source: `omp/packages/coding-agent/src/modes/settings.ts:981-1008`, `predict/client.ts:48-50,234-237`.
- [C] The **UI** only asks for word completion at logical end-of-line. Completion has lower precedence than selected autocomplete hints, whole-message prediction, or the normal inline-hint provider. Source: `omp/packages/tui/src/components/editor.ts:4945-4969,5003-5017`.
- [C] The provider extracts the suffix matching `[\p{L}\p{M}']+`; it rejects a cursor followed by another such character, and uses up to 2,000 UTF-16 units of preceding editor context, avoiding a low-surrogate start when truncating. The current provider also asks about **single-letter prefixes**; engine-specific minimums apply. Source: `omp/packages/tui/src/prompt/word-completion.ts:41-101`.
- [C] Whole-buffer/line caps are **20,000 / 1,000 UTF-16 units**. The current token must not contain any of `\\ / @ _ = : { } [ ] < >`, any digit, or lowercase-then-uppercase camelCase. Lines starting with a trimmed `/`, or literally `->` / `=>`, are excluded. Fenced code, inline code and HTML/XML regions are masked before checking the word. Source: `omp/packages/tui/src/prompt/prose-gate.ts:10-15,27-48,66-75`, `markdown-prose.ts:153-234`.
- [C] **Tab accepts the suffix plus a provisional trailing space; Right Arrow accepts without a space.** OMP can absorb that provisional space before appropriate punctuation. Divergent typing reports negative feedback; typing through a matching suffix is not negative feedback. The provider projects the previous full word while fresh async results are pending. Source: `omp/packages/tui/src/components/editor.ts:2231-2234,4647-4682,4988-5017`; `prompt/word-completion.ts:158-186,214-218`.
- [C] Engine requests are single-flight with only the latest queued query retained, with a 256-entry query cache. Failures return no ghost. The RPC contract uses UTF-16 cursor offsets: `predict_word` returns `suffix|null`; `predict_word_feedback` supplies original text/cursor, suffix and accepted boolean. The RPC docs also specify a roughly 30-second daemon-failure backoff. References: [RPC docs](omp://rpc.md:269-294), local `word-completion.ts:104-125,221-254`.
- [C] `omp predict` compares the actual completion providers/engines in lanes; its Tab accepts the first lane with a trailing space and comparison typing does not teach the engines. Source: `omp/packages/coding-agent/src/cli/predict-cli.ts:1-9,37-40,175-179`; [CLI docs](omp://cli-reference.md:272-286).

### Ranking and learning

- [C] N-gram combines typed history with a compressed offline web prior and absolute-discount/interpolated word bigram/trigram probabilities, then applies a learned case channel. It normalizes candidate probability over **all words under the prefix, including the prefix as a finished word**, and adds prompt-local and recent-session caches. The selected output is the highest-ranked eligible **extension**; the finished word contributes mass but is not itself returned. Default show threshold is **0.15**. Thus a common already-finished prefix reduces confidence; it is not a blanket hard stop. Exact equations/selection: `omp/crates/pi-predict/src/ngram/query.rs:4-16,297-449,531-563`.
- [C] Tuned parameters include `mu1=10000`, `d2=d3=0.9`, `mu2=mu3=2`, web bigram weight 1, unigram top-k 6, unknown-word minimum typed count 2, case prior 0.97, case strength 2, prompt cache weight 0.5 with distance decay 500/context boost 4/window 4000, and session weight 0.02 over 20 prompts. Rare misspellings can canonicalize to a more frequent known spelling. Source: `omp/crates/pi-predict/src/ngram/model.rs:79-108`, `ngram/hygiene.rs`.
- [C] SmolLM uses **SmolLM2-135M**, token-healed prefix-constrained search to a word boundary, prefix-consistent probability mass including the finished-word boundary, KV-prefix reuse, recent-prompt memory, and three alternatives with typed-past exclusion at 0.15. The configured `smollm` path blends n-gram weight **0.3** and LM weight **0.7**, adds their weighted scores on agreement, selects the larger score otherwise, and shows at **0.05**. Without LM it degrades to n-gram at approximately 0.17. Source: `omp/crates/pi-predict/src/smollm/mod.rs:12-18,90-97,368-413`, `packages/coding-agent/src/predict/blend.ts:14-27`.
- [C] Apple uses `NSSpellChecker`, only the current line, and the first case-insensitively extending candidate. Minimum prefix is 2 characters. Confidence is 1 for unfinished words, 0.25 for dictionary-complete words; the default threshold 1 suppresses the latter. It learns/persists nothing. Source: `omp/crates/pi-predict/src/apple/mod.rs:51-60,71-125`.
- [C] **Important correction to the requested mental model:** although the API/docs say feedback tunes learned state, the current n-gram **and SmolLM** `feedback()` implementations are explicitly **no-ops**: source comments say per-prefix accept/reject bias produced no measured gain. N-gram learns submitted prompts; SmolLM remembers recent prompts. Apple feedback is also a no-op. The editor still sends feedback. Source: `omp/crates/pi-predict/src/ngram/mod.rs:184-191`, `smollm/mod.rs:430-437`, `apple/mod.rs:121-123`. This prototype intentionally implements the requested positive/negative feedback rather than copying those no-ops.

[C] The supplied [local-models docs](omp://local-models.md) describe the wider tiny-model workers and runtime-download behavior; the current prediction implementation's exact model/search behavior is clearer in `pi-predict` and `predict/blend.ts`. No OMP binary, daemon, native predictor, or model weights were run here.

## Prototype engine design and limits

- [E/C] **English seed:** use `nixpkgs.scowl`, not a runtime dictionary downloader. The tested derivation is SCOWL 2020.12.07 at the nixpkgs revision recorded in `recommended-pins.json`. `share/dict/wamerican.35` is a plain UTF-8 list with **50,106 lines / 458,219 bytes**, so no hunspell affix parser/helper is needed. The `words` top-level attribute is absent in the tested nixpkgs; `hunspellDicts.en_US` exists but `.dic` flags would need extra parsing/affix handling. A production derivation can copy just this one file instead of retaining every SCOWL dictionary through a runtime symlink.
- [C] The seed is deduplicated/lowercased/sorted once; a binary lower-bound search selects each typed-prefix range. Candidate score is a small local interpolation of a uniform dictionary prior, unigram occurrences, previous-word bigrams and two-word-context trigrams, multiplied by bounded accepted/rejected bias. Confidence is normalized over matching candidates; threshold 0.15. Uppercase prefixes retain uppercase suffixes. There is **no neural model, network client, process execution or external npm dependency** in these two files.
- [E/C] User/assistant text from the active branch and subsequent `message_end` events is learned after code masking; tool output is not indexed. Stable message-content/timestamp hashes prevent repeated branch replay from duplicating the same message. Accepted words immediately contribute counts; rejection subtracts bounded per-prefix candidate bias. Counts, n-grams, feedback and seen IDs are persisted, not raw full prompts. State writes are debounced, serialized, atomic temp/rename, and flushed on shutdown.
- [C] State dimensions are bounded at snapshot time: 30k learned unigrams, 40k bigrams, 40k trigrams, 10k feedback pairs, and 4096 seen message IDs. Dictionary vocabulary is independent. Reads validate the snapshot fields/counts before consuming them; count maps use null prototypes so ordinary words such as `constructor` are not confused with Object methods.
- [E/C] It is **not an exact port of OMP's statistical engine**. It has no compressed web-frequency prior, advanced case channel/canonicalization, neural alternatives/KV cache, or native daemon. Cold dictionary ranks are weaker and deliberately conservative: for example eight equally weighted `configur...` alternatives fall below the threshold, while the narrower `configurat...` prefix completes without any conversation/model call. Domain words absent from the conservative list, such as `refactor`, become available through transcript learning.
- [C] Prototype gates are intentionally somewhat stricter than the current OMP provider: minimum prefix 2 and unfinished inline code is excluded. A finished dictionary word can win and suppress an extension, rather than only contributing denominator mass as OMP does. The Markdown mask is a small conservative implementation, not OMP's full nested HTML/XML parser.
- [C] Tab inserts a normal trailing space, not OMP's punctuation-absorbing provisional-space state. Right inserts no space. The requested WORD/Tab behavior is exercised; that punctuation refinement was not implemented.
- [H] Before productionizing, tune dictionary size/prior and suppression against the user's own typed prose rather than treating this lab's small fixture as a quality benchmark. No end-user keystroke-saving/precision or latency benchmark was performed.

## Open risks and scope boundary

- [C/H] The renderer depends on the currently shipped pi cursor-marker shape and on cursor/line/insertion methods exposed by the tested CustomEditor subclasses. Public `EditorComponent` does not promise all of those methods. Unsupported editors get one warning and no ghost decoration instead of being replaced. Recheck when upgrading pi or changing the visual owner.
- [E/H] Initial mount, native autocomplete, both list orders, `/new` and `/reload` were tested. Live visual settings toggles that install a replacement factory after resource discovery, overlay editors, selection, every undo/history mode and multiple simultaneous pi processes were **not** exhaustively tested. Another late factory replacement can displace ghost until the next discovery/reload; do not combine a separate continuously re-wrapping statusline owner without testing it.
- [C/H] JSON state is serialized atomically **within one pi process**, not merged/locked across independent pi processes. Concurrent processes sharing one agent-dir can overwrite each other's learning. The data remains local but vocabulary/n-grams can still contain sensitive terms; keep the mutable agent directory private and out of Nix/store/version control.
- [E] All authored artifacts and lab runtime homes are under this area's directory; no Nix repo, real pi/omp agent configuration, real secrets or real LLM endpoint was used. An initial failed `nixpkgs#words` query inherited Nix's default evaluation cache (the tool reported the user's cache DB path); subsequent Nix invocations explicitly set this area's `XDG_CACHE_HOME`. SCOWL was realized with the assignment's permitted Nix tooling.
